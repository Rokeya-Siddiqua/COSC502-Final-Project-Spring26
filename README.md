# COSC502-Final-Project-Spring26

This project demonstrates a simple web-based medical image caption retrieval system using Flask. The system allows users to enter a text query and retrieves the top K (5 or 10) most relevant medical image captions using TF-IDF and cosine similarity.

The web interface is designed to accept user queries and display ranked search results in real-time. Additionally, two new custom medical queries were created to test the retrieval performance.
